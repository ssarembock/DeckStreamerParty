Deck Party is the user's Unity rename of Party House (UFO 50 game #25), rules from Party_House_UFO50_Complete_Rules.md. Built 2026-10-29 (single player + NGO 2.13.3 / transport 2.7.4 / services.multiplayer 2.4.1 Relay / multiplayer.playmode 1.6.3). Re-themed 2026-10-30 (MajorUpdate.md, V1Instructions.md). On 2026-10-31 the V2 polish from PlanForPolish.md was implemented (V2Instructions.md = test guide, UIGuide.md = "where to change X"). Player-facing title is **Audience Capture**; productName/repo/project stay "Deck Party".

Key non-obvious decisions:
- Scenes/prefabs are generated by `Deck Party > Setup`; "Build Everything" never overwrites scenes (but re-imports the strings CSV), "Rebuild" does (backs prefabs up to Prefabs/Backup, keeps DeckPartyDatabase portraits). The user only edits art via the Game Database inspector, so Rebuild is acceptable.
- All UI text goes through `Loc.Get(key, named args)` (Runtime/Localization/Loc.cs); master CSV Resources/Localization/AudienceCapture_Strings.csv (en, zh-Hans, ru, es-419 neutral "tú", pt-BR), imported into Unity Localization 1.5.8 tables; CSV is the fallback. Core errors are `Err.Of("key", args)` -> "key|arg" with @g/@a/@s/@t/@w arg tokens. Non-English: swatting = police arrival; title differs per language. Static captions use LocalizedLabel; builders auto-add it for key captions (EditorLoc).
- Core keeps internal names (Pop=Subs, Trouble=Swatting Risk, Star=Diamond, Rolodex=Audience, House capacity=Sub Cap, raid=SWATTED, blame=Temporary Ban, guest=viewer, venue=stream setup).
- Streamers: Core StreamerCatalog (11 + None; RandomPick=255 resolved by host at match start). Rival powers (Raid, Wealth Tax) resolved by host via PartyEngine.UseRivalPower; disabled in single player. Cooldown N stored as N+1, decremented at BeginParty.
- Versions: StateSerializer FormatVersion 6 (reads 2-5), NetworkService protocol "deckparty-8", ProgressStore key "dp.progress.v2". Bump on breaking changes.
- Feel code only in DeckParty.Juice asmdef (Scripts/Juice) behind IFxBackend; SSU via saved uber material (FX/Materials/PortraitUber.mat) because SSU effects are shader_feature keywords. FxLibrary (Data/FxLibrary.asset) holds cues + N1-N14 switches.
- Animated characters render through one PortraitStage render texture on layer "CardPortraits" (31); state names Idle, Idle_Pre_Active, Active, Idle_Post_Active, Score, optional Enter/Exit/Hit/Celebrate; streamers Select/Anxious.
- Multiplayer is open information; presence (PresenceMessage ~0.12 s via host relay) shows active player's hover/targets in their colour. Turn timer (Take Turns only) covers the whole turn; timeout scores the stream and passes the turn.
- Session events are raised through isolated try/catch Raise() helpers (a throwing listener once froze the host). Menu screens that subscribe must unsubscribe in UIScreen.OnUnloaded.
- NGO 3.x requires Unity 6000.7, so stay on NGO 2.x. MonoBehaviours must be one per file (Unity serialization).

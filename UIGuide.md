# Audience Capture UI Guide

A quick reference in the form "to change X, open Y, do Z". It describes the game as of the V2 (Audience Capture) update. For setup and multiplayer hosting see `INSTRUCTIONS.md`; for testing this update see `V2Instructions.md`.

**Paths:** unless stated otherwise, paths are under `Assets/DeckParty/`, and scripts are under `Assets/DeckParty/Scripts/`.

---

## 1. Project map

| Thing | Where | Regenerated by |
|---|---|---|
| Scenes | `Scenes/MainMenu.unity`, `Scenes/Game.unity` | **Rebuild Scenes and UI Prefabs (overwrites)** only |
| Scene builders (useful as a reference for every object) | `Scripts/Editor/MainMenuSceneBuilder.cs`, `GameSceneBuilder.cs`, `StreamerSelectBuilder.cs`, `SceneCommon.cs` | – |
| UI prefabs | `Prefabs/UI/` (GuestCard, GuestRow, ScenarioItem, PlayerRow, TextLine) | **Rebuild** only. The old ones are backed up to `Prefabs/Backup` first. |
| Card and row layout numbers | `Scripts/Editor/DeckPartyAssets.cs`, class `CardLayout` | – |
| View scripts | `Scripts/Runtime/UI/` (Game, Menu, Common) | – |
| Game Database (portraits, streamers, venues, FX and portrait stage links) | `Resources/DeckPartyDatabase.asset` (**Deck Party > Select Game Database**) | Never overwritten. New entries are only added. |
| UI Skin (sprites and fonts) | `Data/UISkin.asset` | Never overwritten |
| Stream setups (venues) | `Data/Venues/Venue_*.asset` | Never overwritten. Missing ones are created. |
| FX Library (Feel cues, SSU materials, polish switches) | `Data/FxLibrary.asset` (**Deck Party > FX > Select FX Library**) | **FX > Rebuild FX (overwrites)** regenerates the prefabs and materials but keeps the switches |
| Feel feedback prefabs | `FX/Feedbacks/FX_<Moment>.prefab` | Same as above |
| SSU uber materials | `FX/Materials/PortraitUber.mat`, `ShineUber.mat` | Same as above |
| Text (all languages) | `Resources/Localization/AudienceCapture_Strings.csv`, imported into `Localization/Tables` | **Build Everything** re-imports the CSV (section 7) |
| Fonts | `Fonts/*.ttf` (OFL licences next to them) and the generated `Fonts/*.asset` | **Localization > Rebuild Fonts** |
| Animation templates and portrait stage | `Animation/AC_CharacterTemplate.controller`, `AC_StreamerTemplate.controller`, `Prefabs/PortraitStage.prefab` | Created if missing; never overwritten |

**Build Everything vs Rebuild:**
- **Build Everything (keeps existing scenes)** only creates what's missing. It also re-imports the strings CSV.
- **Rebuild Scenes and UI Prefabs (overwrites)** regenerates both scenes and the 5 UI prefabs. Your edits to those are lost; everything else is kept.

If you hand-edit a scene, keep a note of what you changed or stop using Rebuild.

## 6. Character art and animations

| You have | Put it here | Notes |
|---|---|---|
| A still sprite | Database > Guests > the viewer > **Portrait** (or drop `doge.png` into `Art/Characters`) | Square-ish, transparent, 512x512. Shown in a 180x178 area. |
| A rigged PSB or an animated prefab | **Animation...** > **Character Prefab** | It must contain an Animator. |
| Clips for a sprite | **Animation...** > **Create Override Controller**, then fill the slots in `Animation/Characters/<Viewer>_Override` | The override is based on `AC_CharacterTemplate` |
| Streamer art | Database > **Streamers** (Portrait on each row; Character Prefab / Animator Controller under **More...**), or `streamer_<name>.png` | Streamer states: Idle, Select, Anxious, plus optional Hit and Celebrate (played in the facecam) |

**State names (exact):** `Idle`, `Idle_Pre_Active`, `Active`, `Idle_Post_Active`, `Score`, plus optional `Enter`, `Exit`, `Hit`, `Celebrate`.
- **Fallbacks:** missing states fall back (`Idle_Pre/Post_Active` to `Idle`, `Score` to `Celebrate`).
- **One-shots:** `Active`, `Enter`, `Exit` and `Hit` play once and return to the resting state.
- **Shop and pickers:** the shop, Audience view and pickers show `Idle_Pre_Active`.
- **Without an animation:** a missing `Active` or `Score` gets a Feel punch instead.

**Framing:** **Framing Zoom** and **Framing Offset** on each entry.

**Validator:** **Deck Party > Art > Validate Character Animations** lists missing states and clips that animate paths the prefab doesn't have.

**How it renders:**
- **The stage:** animated characters stand on a hidden layer (**CardPortraits**). One camera renders them into a shared texture with 8x8 cells of 256 px (6x6 cells of 384 px at 1440p and above), and each card shows its cell.
- **Cost:** cards with only a still sprite skip the stage entirely.
- **Settings:** `Prefabs/PortraitStage.prefab`, which uses `Animation/PortraitUnlit.mat`.

## 7. Text and languages

**The CSV is the master copy:** `Resources/Localization/AudienceCapture_Strings.csv`.
- **Columns:** Table, Key, Context, English, 简体中文, Русский, Español (Latinoamérica), Português (Brasil), Status.
- **Saving:** open it in Excel or Google Sheets and save as **CSV UTF-8**.
- **Fallback:** the game reads the CSV directly if the string tables are missing.

| To | Do |
|---|---|
| Change any text | Edit the cell, then **Deck Party > Localization > Import CSV into String Tables**. In the editor, **Build Everything** also re-imports it. |
| Edit inside Unity instead | **Window > Asset Management > Localization Tables**. Then run **Localization > Export String Tables to CSV** *before* the next Build Everything, or the CSV import overwrites your edits. |
| Use placeholders | `{name}` placeholders must stay exactly as in English. Plurals look like `{count:plural:viewer|viewers}`; Russian takes 3 forms (`one|few|many`), Chinese 1. `\n` is a line break. Rich text (`<b>`, `<color=#...>`) is allowed. |
| Caption a static text in a scene | Add **LocalizedLabel** with a key (plus an optional prefix or suffix). The builders do this automatically for every caption that is a CSV key. |
| Use text from code | `Loc.Get("key", "name", value, ...)`. Rules-engine errors are `Err.Of("key", args)`. |
| Add a language | Add a column to the CSV (header = the language's display name). Add it to `Loc.Languages` in `Runtime/Localization/Loc.cs` (code + column name) and to the plural rules if needed. Then run Build Everything (it creates the locale) and re-import. |
| Find untranslated or overflowing text | Pick **Pseudo** in Settings > Language (editor and development builds). Real text is stretched and accented, so plain English is a missed string. |
| Fix squares / missing glyphs | **Deck Party > Localization > Rebuild Fonts**. All fonts are dynamic with fallbacks: Noto Sans SC covers Chinese, and Noto Sans covers Cyrillic and accents. |
| Use your own font | Make a TMP font asset (dynamic). Assign it to the UI Skin, then add `Fonts/NotoSans SDF` and `Fonts/NotoSansSC SDF` to its **Fallback Font Assets** so other languages still render. |

Language-specific terms: the title differs per language (`menu.title`). Deplatform Risk, DEPLATFORMED! and Server Down are `term.risk`, `term.raid` and `term.overload`. Resources are never written as words in game text: use `{icon:subs}`, `{icon:cash}` and `{icon:risk}` (their names live in `term.*` and the `hud.tip.*` tooltips). Communities are `community.<Community>.name / .desc / .now`.

## 8. Feel (game feel)

**Deck Party > FX > Select FX Library**.
- **Each moment:** has a Feel feedback prefab, an **Intensity** (0 to 2) and an on/off switch.
- **Global multipliers:** **Duration Multiplier** and **Shake Multiplier**. The player's Fast Animations and Screen Shake settings apply on top.

| Moment | Plays when |
|---|---|
| ViewerJoined / DiamondJoined | A card arrives in chat |
| CardHover / ButtonPress / ButtonDenied | Hovering a card; pressing a button; a rejected click |
| AbilityUsed, then ImpactRecruit / Remove / Modify / Shuffle / Scout / Economy | The acting card, then the target, by action type |
| CounterPunch / RiskPip / SubCapFull / DiamondTracker | HUD numbers change; a risk pip fills; chat is full; the Diamonds meter goes up |
| PlatformBan / ServerDown / Victory / Defeat | The big moments (with banner and shake) |
| ScoreTick | Each viewer in the scoring sequence |
| TurnBanner / BoardSwitch / BannerSlam / ToastIn / MenuIn | Turn changes, switching boards, banners, toasts, menus opening |
| StreamerAnxious | The anxious streamer's intermittent shake |
| PowerUsed / Purchase / Stamp / SelectConfirm | Streamer power, buying a viewer, comic stamps, confirming a streamer |
| ScreenShake | Generic shake |

| To | Do |
|---|---|
| Tweak a moment | Open `FX/Feedbacks/FX_<Moment>.prefab` and edit its MMF_Player feedbacks. The feedbacks target their **parent** (Automated Target Acquisition: Parent), so they work on any card or panel. |
| Swap in your own feedback | Make a prefab with an MMF_Player whose feedbacks target the parent, and drop it into that cue's **Feedback** slot. |
| Turn a moment off | Untick **Enabled** on the cue |
| Start over | **Deck Party > FX > Rebuild FX (overwrites)** |

Without Feel, the game falls back to simple built-in tweens (`Runtime/Fx/Fx.cs`). Feel code lives only in the `DeckParty.Juice` assembly (`Scripts/Juice`).

## 9. Sprite Shaders Ultimate

Card portraits use one **uber material** (`FX/Materials/PortraitUber.mat`, shader *Sprite Shaders Ultimate/GUI SSU*).
- **How it works:** every effect the game drives is enabled with its Fade at 0, and each card fades effects in on its own material instance.
- **Why it's set up this way:** builds only contain shader variants that a saved material uses.

| Status / moment | SSU effect |
|---|---|
| Selected / selectable / carries risk / risk cleared | Outer Outline (pink / gold / red / teal) |
| Action still available / attached or protected / Pepe's mood | Sine Glow (purple / pink / mood colour) |
| Infected (Skibidi) | Poison |
| Immune (Roll Safe) | Frozen |
| Zeroed | Saturation 0 |
| Double (Drakeposting) / Diamond | Shine (gold) |
| Converted (Math Lady) | Add Hue |
| Temporary copy (Knuckles) | Hologram |
| Rickrolled | Random Glitch (off with Reduce Flashing) |
| Temporary Ban (Audience view) | Desaturate + Hologram (a grey, flickering dead feed) |
| Arrival / kick / Rickroll / hit pulses | Full Glow Dissolve / Burn / Glitch / Pixelate / Vibrate |

| To | Do |
|---|---|
| Change a colour or strength | `Runtime/Fx/CardFx.cs`, `SetStatus` and `Pulse` |
| Change an effect's look (width, speed, texture) | Edit `PortraitUber.mat`. Each card copies it at start. |
| Add an effect | Enable it on the uber material (keyword plus `_Enable<Effect>`, Fade 0), add its fade to `CardFx.AllFades`, and drive it in `SetStatus`. Also add it to `s_UberEffects` in `Scripts/Editor/Fx/FxSetup.cs`, so a rebuild keeps it. **Careful with SSU's "Fading" effects** (Halftone, the Dissolves, Directional Fades, Custom Fade): their Fade is how much of the sprite remains, so Fade 0 makes the portrait invisible. Halftone did exactly that until V2.1. The one the cards use, Full Glow Dissolve, rests at 1 and only dips during the arrival. |
| The shining button (End the Stream & WIN!) and the title | `FX/Materials/ShineUber.mat` |

## 12. Troubleshooting

| Problem | Fix |
|---|---|
| My scene edits vanished | **Rebuild Scenes and UI Prefabs** overwrites them. Use **Build Everything** instead, which never touches existing scenes. |
| My text edits in the Localization Tables window vanished | Build Everything re-imports the CSV. Export to CSV first (section 7). |
| A caption stays English in other languages | It has no **LocalizedLabel**, or its key is missing from the CSV. Pseudo makes these easy to spot. |
| Text shows `[some.key]` | The key isn't in the CSV. Add the row and re-import. |
| Text overflows in Russian or Portuguese | Every TMP text auto-sizes down to 60%. If it still overflows, widen the box or shorten that language's cell. |
| Squares instead of characters | **Localization > Rebuild Fonts**. If you use your own font, check it has the Noto fallbacks. |
| Cards look plain (no glow or outline) | **FX > Rebuild FX**. Check the **Status Effects** switch and that Sprite Shaders Ultimate is installed. |
| Effects missing in a build but fine in the editor | An SSU effect was used that isn't on the uber material. Add it as in section 9. |
| Animated character invisible | Validate Character Animations. Check the **CardPortraits** layer exists and the database's **Portrait Stage** is set. |
| UI too wide on a 32:9 monitor | That's the 21:9 cap working. Raise `ContentFrame.maxAspect` if you want it wider. |
